# whack-a-mole
A basic whack-a-mole game, with four buttons that start, pause, resume and restart the game when clicked.
A few other features of the game include a mole that disappears momentarily when the mole has been clicked, a score that counts as the mole is clicked, and a timer that tells the user how much time they have left

# Buttons
Start- starts the game
Pause- pauses the game
Resume- resumes the game
Restart- restarts the game
